# CodeAlpha_BasicChatbot
# Task 4: Basic Chatbot

## Objective
Build a simple rule-based chatbot.

## Simplified Scope
- Accept user inputs such as:
  - hello
  - how are you
  - bye
- Return predefined responses.
- Continue chatting until the user enters "bye".

## Features
- Responds to greetings
- Answers predefined questions
- Handles unknown inputs
- Ends the conversation when the user types "bye"

## Key Concepts Used
- if-elif statements
- Functions
- Loops
- Input/Output

## Requirements
- Python 3.x

## How to Run
1. Open the project in Visual Studio Code.
2. Run the Python file.
3. Enter:
   - hello
   - how are you
   - bye
4. View the chatbot responses.

## Note
GitHub Codespaces usage limit was reached. 
Please run the project locally using VS Code + Python 3.


## Conclusion
This project demonstrates the implementation of a simple rule-based chatbot using Python functions, loops, conditional statements, and user input/output.
